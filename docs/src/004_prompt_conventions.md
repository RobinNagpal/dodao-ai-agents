# Instructions and Information
When we write a prompt always write all the instructions first in the first and tell in the prompt that below is
the information. Make sure its easy for the LLM to find the information.

# Use Headings
MAny times we combining and sending 4-5 types of information to LLM. We should use headings to make it easy for LLM 
to differentiate between the information.

Things like score tables, or calculated metrics should have proper headings before we use them in the next prompt.

We can add headings easily in the prompt by using markdown format like `#`, `##`, `###` etc.
